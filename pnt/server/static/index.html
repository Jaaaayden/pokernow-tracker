PokerNow Tracker

A queryable database of every hand, keyed to stable player identity. The stats are derived when you ask for them, never stored — so a definition can change and the history still answers to it.

Stats →

Every player, sortable. Pick a street, filter to a spot, click through to a range.

Range chart →

What someone had in a spot — the 13×13 grid, made hands, or bet sizing.

Hand review →

Missed bluffs, missed value and bluffs that got called — and the bad beats, on a tab of their own.

Biggest pots →

The pots that actually mattered this week — over 2,000 chips in the last 7 days, biggest first, with the replay a click away.

All-in EV →

Did the jams run above or below their equity? Actual against adjusted, per player and per hand.

Players & identities →

Merge one human's two devices, split a bad merge, rename. The only upkeep this needs.

API →

Every endpoint these pages use, with a try-it form. The database is also just a file.

Keeping it running

pnt service status
Is the background server up, and which database has it open
pnt service restart
Run after changing code — a running server keeps the old copy
pnt service log
The last lines of the server log
pnt extension
The folder to give Chrome's Load unpacked
pnt import
Backfill from PokerNow CSV exports; re-importing is free. Reads ~/Downloads/pokernow-logs unless you pass a path, --log-dir, or set PNT_LOG_DIR
pnt where
Which database, log folder and extension folder this install is actually using

If the HUD is empty

no panel at all
The extension is not loaded, or the tab is not a pokernow.com/games/… page. Reload the tab after loading it.
“tracker not reachable
at http://…”
The extension prints the exact address it tried. If that address is not the one in this page's address bar, the extension is looking in the wrong place — open its toolbar popup and correct the server field. If it is the same address, the server has stopped: pnt service status.
“waiting for the first hand”
Connected, but this table has no complete hand stored yet. It fills in as hands finish.
everyone shows “–”
Real: an unknown rate, not a zero. They have had no opportunity for that stat yet.

port 52000, chosen to stay out of the way of anything else you run locally — 8000 and 8080 are the contested ones. Change it with pnt service install --port N, and set the same address in the extension's popup.
